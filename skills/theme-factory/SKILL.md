# Theme Factory

A curated collection of professional font and color themes, each with carefully selected palettes and font pairings. Once a theme is chosen, it can be applied to any artifact.

## Purpose

Apply consistent, professional styling to presentation slide decks and other artifacts. Each theme includes:
- A cohesive color palette with hex codes
- Complementary font pairings for headers and body text
- A distinct visual identity suitable for different contexts and audiences

## Usage Instructions

1. **Show the theme showcase**: Display the `theme-showcase.pdf` file so users can see all available themes visually. Do not modify it; simply show it for viewing.
2. **Ask for their choice**: Ask which theme to apply to the artifact
3. **Wait for selection**: Get explicit confirmation about the chosen theme
4. **Apply the theme**: Apply the selected theme's colors and fonts to the artifact

## Available Themes

The following 10 themes are available, each showcased in `theme-showcase.pdf`:

1. **Ocean Depths** — Professional and calming maritime theme
2. **Sunset Boulevard** — Warm and vibrant sunset colors
3. **Forest Canopy** — Natural and grounded earth tones
4. **Modern Minimalist** — Clean and contemporary grayscale
5. **Golden Hour** — Rich and warm autumnal palette
6. **Arctic Frost** — Cool and crisp winter-inspired theme
7. **Desert Rose** — Soft and sophisticated dusty tones
8. **Tech Innovation** — Bold and modern tech aesthetic
9. **Botanical Garden** — Fresh and organic garden colors
10. **Midnight Galaxy** — Dramatic and cosmic deep tones

Full specifications (hex codes, font pairings) for each theme are in the `themes/` directory.

## Application Process

After a theme is selected:
1. Read the corresponding theme file from `themes/`
2. Apply the specified colors and fonts consistently throughout the artifact
3. Ensure proper contrast and readability
4. Maintain the theme's visual identity across all elements

## Create a Custom Theme

When none of the 10 existing themes work, generate a custom theme:
1. Based on provided inputs, choose appropriate colors and fonts
2. Name the theme descriptively (e.g., "Corporate Slate", "Tropical Warmth")
3. Show the generated theme for review and verification
4. Apply the theme as described above
